# Survive Drive development baseline

- Use this Valhalla repository's `main` branch as the starting point for future Survive Drive work. The user promoted it to the primary development baseline on September 28, 2026.
- Keep the HERE version and its `choppy.fans` deployment separate. Do not replace that public address merely because this repository is now the development baseline.
- Preserve Escape Gates and the full start/destination gate cross product unless the user changes that requirement.
- Before new AVM sampling, run Round 0 on known coverage. Its nominal INCLUDED quota is `N - ceil(N/3)` from the original `N` candidates, but protect every route below 20% known coverage even if this exceeds the quota. Apply the cell count only to INCLUDED routes. Keep exact provider ceilings and no automatic retries.
- After each completed evidence reranking, advance the cull number and exclude the bottom one-third (rounded up) of the previous nominal quota and fill the remaining INCLUDED slots from the full current ranking. Prior inclusion does not reserve a slot; previously EXCLUDED routes can be promoted. A reranking without a completed evidence round substitutes routes within the current quota without shrinking it.
- Build and verify changes offline before publishing the Valhalla Site. Do not send live provider requests solely to test code.
- Verify the requested outcome through the actual action and its resulting data, not only control visibility, readiness or layout. For gate regeneration, exercise repeated GO with unchanged settings and inspect both returned gate sets. Use offline fixtures unless the user explicitly authorizes a public runtime check.
- Preserve the permanent original-endpoint contract enforced by `check-endpoint-contract.mjs` on every build. Validate actual path endpoints against the reviewed original Start/Destination, using geodesic distance and a 100 metre maximum; echoed or snapped provider coordinates are not authoritative. Missing original coordinates fail validation. Recheck saved candidates and chosen path snapshots before selection, export, phone storage, and phone navigation. Never weaken the checks to make a fixture pass.
- Coverage must produce usable routes, rather than merely reject incomplete routes. Serve the complete verified U.S. graph when available; never present city-buffer coverage as whole-country coverage. Build new road data separately and verify it before activation. Never delete AVM evidence or alter the permanent AVM grid to repair road coverage.
