# Survive Drive · Local Valhalla

Double-click **Open Local Valhalla.cmd**. It starts the routing engine and opens [the local route page](http://127.0.0.1:8003/) in your default browser. The engine and page listen only on this computer. After a Windows restart, run the launcher again.

The local page lets you set a start, destination, and optional fuzzy waypoints on a map or by coordinates. Each waypoint is visited in order with an 800 meter road search radius, using `via` rather than `through`: a U-turn is allowed at the waypoint, without adding a stop or leg boundary. Gate road candidates use `rank_candidates: false`, so proximity to the pin does not penalize an otherwise efficient route. The desktop engine's `service_limits.max_radius` is 1600 meters; the launcher preserves this cap. Without waypoints, Valhalla may return up to four alternatives. Every **Search routes** click sends one local request. It never retries automatically. The page is for routing only; AVM evaluation and the full review workflow remain in the separate published offshoot.

The primary desktop graph covers 343 U.S. cities over 100,000 population with 20-mile surrounding buffers. A separate complete Florida graph covers Florida trips, including Naples, which falls outside the city extract. The launcher starts this engine on loopback port 8100 when `data/tiles-florida` exists and writes `regional-engines.json` beside the request ledger. The bridge selects this complete graph before sending a Florida request; other requests use the primary graph. It sends the entire trip, including all gates, to one engine and never retries against another. Florida eligibility uses the state bounding box, so points outside actual loaded roads still fail the strict endpoint checks. Graph files are never mixed or deleted. The retained Florida source is dated September 28, 2026; the national city source is October 8, 2026. The service uses the `pyvalhalla` 3.9.0 Windows package and Geofabrik OpenStreetMap extracts for [Illinois](https://download.geofabrik.de/north-america/us/illinois.html), [Indiana](https://download.geofabrik.de/north-america/us/indiana.html), [Ohio](https://download.geofabrik.de/north-america/us/ohio.html), [Kentucky](https://download.geofabrik.de/north-america/us/kentucky.html), [Florida](https://download.geofabrik.de/north-america/us/florida.html), Southern California, and [Texas](https://download.geofabrik.de/north-america/us/texas.html).

Texas was added from the October 4, 2026 extract with its publisher checksum verified. The combined graph is built in `data/tiles-expanded-texas`, with all earlier regions and existing routing/exclusion limits preserved. `verify-expanded-texas.py` in the runtime folder checks Texas routes and every existing region directly against the staged graph without HTTP or AVM calls. The earlier graph remains in `data/tiles-expanded-socal` for recovery; its configuration is saved as `valhalla.before-texas-20261005.json`.

The [published offshoot](https://survive-drive-valhalla.choppy777.chatgpt.site/) also has a local connection check. Its private sign-in and the browser's local network controls may prevent that hosted page from reaching this computer. The local page avoids that connection boundary.

For diagnostics, `http://127.0.0.1:8002/status` checks Valhalla and `http://127.0.0.1:8003/status` checks the local page and bridge. Request IDs are recorded in `work/valhalla-local/claims.jsonl` to prevent a repeated attempt after a restart.
